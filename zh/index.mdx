## 快速示例

几秒钟即可发出你的第一个请求:

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-hapuppy-xxx",
    base_url="https://beta.hapuppy.com/v1"
)

response = client.chat.completions.create(
    model="claude-sonnet-4-20250514",
    messages=[
        {"role": "user", "content": "Hello from Hapuppy!"}
    ]
)

print(response.choices[0].message.content)
```

```typescript TypeScript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "sk-hapuppy-xxx",
  baseURL: "https://beta.hapuppy.com/v1",
});

const response = await client.chat.completions.create({
  model: "claude-sonnet-4-20250514",
  messages: [
    { role: "user", content: "Hello from Hapuppy!" }
  ],
});

console.log(response.choices[0].message.content);
```

```bash cURL
curl https://beta.hapuppy.com/v1/chat/completions \
  -H "Authorization: Bearer sk-hapuppy-xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-sonnet-4-20250514",
    "messages": [
      {"role": "user", "content": "Hello from Hapuppy!"}
    ]
  }'
```

</CodeGroup>
