---
title: "获取模型"
description: "检索某个特定模型的详细信息。"
---

```
GET https://api.hapuppy.com/v1/models/{model_id}
```

返回单个模型的元数据。在发送对话 / 嵌入 / 图像请求之前,可用它确认某个模型当前是否可用,或查看其背后的提供方。

## 路径参数

<ParamField path="model_id" type="string" required>
  模型标识符(例如 `gpt-4o`、`claude-sonnet-4-20250514`)。参见[列出模型](/zh/api-reference/models/list)以发现有效的 ID。
</ParamField>

## 响应

<ResponseField name="id" type="string">
  模型标识符。
</ResponseField>

<ResponseField name="object" type="string">
  恒为 `model`。
</ResponseField>

<ResponseField name="created" type="integer">
  该模型在 Hapuppy 上首次可用时的 Unix 时间戳。
</ResponseField>

<ResponseField name="owned_by" type="string">
  上游提供方(`anthropic`、`openai`、`google` 等)。完整列表参见[列出模型](/zh/api-reference/models/list#common-owned-by-values)页面。
</ResponseField>

## 示例

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-hapuppy-xxx",
    base_url="https://api.hapuppy.com/v1"
)

model = client.models.retrieve("claude-sonnet-4-20250514")
print(model.id, model.owned_by)
```

```typescript TypeScript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "sk-hapuppy-xxx",
  baseURL: "https://api.hapuppy.com/v1",
});

const model = await client.models.retrieve("claude-sonnet-4-20250514");
console.log(model.id, model.owned_by);
```

```bash cURL
curl https://api.hapuppy.com/v1/models/claude-sonnet-4-20250514 \
  -H "Authorization: Bearer sk-hapuppy-xxx"
```

</CodeGroup>

## 响应示例

```json
{
  "id": "claude-sonnet-4-20250514",
  "object": "model",
  "created": 1715630400,
  "owned_by": "anthropic"
}
```

## 错误

| 状态码 | 错误代码 | 含义 |
|---|---|---|
| `404` | `model_not_found` | 该模型 ID 不存在,或未被 Hapuppy 公开提供。 |
| `401` | `invalid_api_key` | API 密钥缺失、格式错误或已被吊销。 |

<Info>
  本端点只是一次轻量的元数据查询。已购买积分的账户可调用它返回的全部模型,无需单独申请。
</Info>
