title: "快速开始"
description: "5 分钟内上手 Hapuppy。"
---

<Steps>

<Step title="创建账户">
  前往 [hapuppy.com/register](https://hapuppy.com/register) 注册一个账户。
</Step>

<Step title="购买积分包">
  购买一次性积分包。存入金库的积分永不过期,付费账户可调用全部模型。

  | 积分包 | 价格 | 积分 | 说明 |
  |------|-------|---------|-------|
  | Lite | $9.99 一次性 | 30M | 全部模型,永不过期 |
  | Standard | $19.99 一次性 | 120M | 全部模型,永不过期(热门) |
  | Pro | $36.99 一次性 | 240M | 全部模型 + 优先路由,永不过期 |

  所有账户的速率限制均为 100 RPM。请通过[积分包(Credits Packs)](https://hapuppy.com/en/dashboard/billing)页面购买;支付经由 Creem 处理。
</Step>

<Step title="生成 API 密钥">
  进入 **Dashboard → API Keys**,点击 **Create Key**。你的密钥形如:

  ```
  sk-hapuppy-xxxxxxxxxxxxxxxxxxxxx
  ```

  <Warning>
    请妥善保管你的 API 密钥。不要分享,也不要将其提交到版本控制中。
  </Warning>
</Step>

<Step title="发出你的第一个请求">
  使用任意兼容 OpenAI 的 SDK,或直接发起 HTTP 请求。

  <CodeGroup>

  ```python Python
  from openai import OpenAI

  client = OpenAI(
      api_key="sk-hapuppy-xxx",
      base_url="https://api.hapuppy.com/v1"
  )

  response = client.chat.completions.create(
      model="claude-sonnet-4-20250514",
      messages=[
          {"role": "user", "content": "What is the meaning of life?"}
      ]
  )

  print(response.choices[0].message.content)
  ```

  ```typescript TypeScript
  import OpenAI from "openai";

  const client = new OpenAI({
    apiKey: "sk-hapuppy-xxx",
    baseURL: "https://api.hapuppy.com/v1",
  });

  const response = await client.chat.completions.create({
    model: "claude-sonnet-4-20250514",
    messages: [
      { role: "user", content: "What is the meaning of life?" }
    ],
  });

  console.log(response.choices[0].message.content);
  ```

  ```bash cURL
  curl https://api.hapuppy.com/v1/chat/completions \
    -H "Authorization: Bearer sk-hapuppy-xxx" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "claude-sonnet-4-20250514",
      "messages": [
        {"role": "user", "content": "What is the meaning of life?"}
      ]
    }'
  ```

  </CodeGroup>
</Step>

<Step title="尝试不同的模型">
  替换 `model` 参数,即可试用任意支持的模型(实时列表见[模型(Models)](https://hapuppy.com/en/dashboard/models)页面):

  ```python Python
  # Try GPT-4o
  response = client.chat.completions.create(
      model="gpt-4o",
      messages=[{"role": "user", "content": "Hello!"}]
  )

  # Try Gemini
  response = client.chat.completions.create(
      model="gemini-2.5-pro-preview-05-06",
      messages=[{"role": "user", "content": "Hello!"}]
  )

  # Try DeepSeek
  response = client.chat.completions.create(
      model="deepseek-chat",
      messages=[{"role": "user", "content": "Hello!"}]
  )
  ```

  在[模型(Models)](https://hapuppy.com/en/dashboard/models)页面查看可用模型的完整列表。
</Step>

</Steps>
