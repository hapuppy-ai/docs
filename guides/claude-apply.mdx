Hapuppy offers Claude models in two flavours:

- **Unprefixed** (e.g. `claude-opus-4-7`, `claude-sonnet-4-6`) — the standard Claude experience.
- **`hapuppy/` prefix** (e.g. `hapuppy/claude-opus-4-7`, `hapuppy/claude-sonnet-4-6`) — the same underlying models, but configured to allow **role-play (RP)** scenarios that the standard variants refuse.

Both variants are gated by a single application at [Claude Apply](https://hapuppy.com/zh/dashboard/claude-apply). Reviews are **manual** — we read each application by hand to prevent abuse of upstream capacity.

## Who needs to apply?

| Variant | Examples | Access |
|---|---|---|
| Unprefixed Claude | `claude-opus-4-7`, `claude-sonnet-4-6`, `claude-haiku-4-5-*` | Free for all approved users — submit a Claude Apply request to unlock |
| `hapuppy/` prefix (RP-enabled) | `hapuppy/claude-opus-4-7`, `hapuppy/claude-sonnet-4-6`, `hapuppy/claude-haiku-4-5-*` | Paid — requires Claude Apply approval **and** a credit pack; consumed at the `hapuppy/` multiplier (see [Credits & Pricing](/guides/credits#chat-models)) |

In short: **everyone who wants any Claude model needs to apply.** The application is the same — approval unlocks both variants at once. Whether you actually use the `hapuppy/` prefix is then your choice on a per-request basis.

## Prerequisites

Before applying, you must:

1. Have a **verified account** — see [Verify Account](/guides/verify-account).
2. Understand the variant policy:
   - Unprefixed Claude is **free to use** after approval.
   - `hapuppy/`-prefixed Claude is **paid** and draws from your credit pack at the multipliers shown on the [Models](https://hapuppy.com/en/dashboard/models) page.
3. Have a brief description of your intended use case ready.

## How to apply

<Steps>

<Step title="Open the application form">
  In the dashboard, navigate to **Models → [Claude Apply](https://hapuppy.com/zh/dashboard/claude-apply)**.
</Step>

<Step title="Describe your use case">
  Provide a short summary (a few sentences) of:

  - What you're building (production app, research, agent, internal tool, role-play companion, etc.)
  - Whether you intend to use the `hapuppy/` RP variants
  - Rough expected request volume

  <Note>
    You do not need to share proprietary details. A general description is sufficient — for example, "code review agent for an internal team, ~5K requests/day" or "interactive fiction prototype using hapuppy/claude-sonnet-4-6".
  </Note>
</Step>

<Step title="Submit and wait for manual review">
  All applications are reviewed by a human. Turnaround is usually within a few days, but there's no hard SLA.

  <Warning>
    **We do not send approval emails.** Check the [Claude Apply](https://hapuppy.com/zh/dashboard/claude-apply) page in the dashboard from time to time — the application's status updates there when a decision is made.
  </Warning>
</Step>

<Step title="Start using Claude">
  Once the page shows your application as approved, Claude model IDs start working immediately — no client-side change required.

  ```python Python
  # Unprefixed — free Claude access after approval
  resp = client.chat.completions.create(
      model="claude-opus-4-7",
      messages=[{"role": "user", "content": "Hello!"}]
  )

  # hapuppy/ prefix — paid, RP-enabled variant
  resp = client.chat.completions.create(
      model="hapuppy/claude-opus-4-7",
      messages=[{"role": "user", "content": "Hello!"}]
  )
  ```
</Step>

</Steps>

## What if I'm rejected?

A rejection just means the manual review didn't pass this time. There's no cooldown — you can **submit a new application right away** from the same [Claude Apply](https://hapuppy.com/zh/dashboard/claude-apply) page.

If you're unsure why an application keeps getting rejected, contact [support@hapuppy.com](mailto:support@hapuppy.com) with your account email.

<Info>
  Approval is per account, not per API key. If you generate a new key, your Claude access carries over automatically.
</Info>
