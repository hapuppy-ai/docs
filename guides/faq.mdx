<Accordion title="What is Hapuppy?">
  Hapuppy is an AI API gateway that lets you access 100+ AI models (Claude, GPT, Gemini, Grok, DeepSeek, Mistral, Llama, GLM, and more) through a single API key. It's fully compatible with the OpenAI API format, so it works as a drop-in replacement in any tool or SDK that supports OpenAI.
</Accordion>

<Accordion title="How is Hapuppy different from using provider APIs directly?">
  - **One API key** for all models — no need to manage separate accounts and keys for each provider
  - **One-time pricing** — pay once for a credit pack that never expires, instead of per-token billing
  - **OpenAI-compatible** — works with any tool or SDK that supports the OpenAI format
  - **Easy model switching** — change the `model` parameter to try different models instantly
</Accordion>

<Accordion title="Which models are supported?">
  Hapuppy supports 100+ models from providers including Anthropic (Claude), OpenAI (GPT), Google (Gemini), xAI (Grok), DeepSeek, Mistral, Meta (Llama), and Zhipu (GLM). See the [Models](https://hapuppy.com/models) page for the full list.
</Accordion>

<Accordion title="Is Hapuppy compatible with the OpenAI SDK?">
  Yes. Hapuppy is a drop-in replacement for the OpenAI API. Simply set your base URL to `https://api.hapuppy.com/v1` and use your Hapuppy API key. Both the Python and TypeScript OpenAI SDKs are fully supported.
</Accordion>

<Accordion title="What tools does Hapuppy work with?">
  Hapuppy works with any tool that supports the OpenAI API format, including:
  - **Claude Code** — Anthropic's CLI tool
  - **Cursor** — AI code editor
  - **Cline** — VS Code AI assistant
  - **Continue** — Open-source AI code assistant

  See the [Integrations](/guides/integrations) page for setup instructions.
</Accordion>

<Accordion title="How does pricing work?">
  Hapuppy offers a free tier plus three one-time credit packs:
  - **Free** — 100K credits per day (resets daily), basic models
  - **Lite** — $9.99 one-time, 30M credits, all 100+ models
  - **Standard** — $19.99 one-time, 120M credits, all models (most popular)
  - **Pro** — $36.99 one-time, 240M credits, all models + priority routing

  Purchased credits enter your **vault** and never expire. Credits are consumed based on token usage with per-model multipliers. See [Credits & Pricing](https://hapuppy.com/credits) for details.
</Accordion>

<Accordion title="Do credits expire?">
  Credits in your **vault** (purchased via a one-time pack) never expire — use them at your own pace. Free-tier credits reset each day; whatever's left at the end of the day does not carry over.
</Accordion>

<Accordion title="What happens when I run out of credits?">
  API requests will return a `429` error.

  - **Free tier**: your 100K daily allowance resets the next day. You can also purchase any credit pack to top up your vault.
  - **Paid users**: purchase another credit pack from the [dashboard](https://hapuppy.com/dashboard) — newly purchased credits stack into your vault.
</Accordion>

<Accordion title="What is the rate limit?">
  All plans have a rate limit of 100 requests per minute (RPM). If you exceed this limit, you'll receive a `429` error.
</Accordion>

<Accordion title="Does Hapuppy support streaming?">
  Yes. Set `stream: true` in your request to receive tokens as they are generated. See the [Chat Completions](/api-reference/chat/completions#streaming) docs for examples.
</Accordion>

<Accordion title="Does Hapuppy support function calling?">
  Yes. Function calling (tool use) is supported for models that natively support it, such as GPT-4o, Claude Sonnet/Opus, and Gemini Pro. See [Chat Completions](/api-reference/chat/completions#function-calling) for examples.
</Accordion>

<Accordion title="Does Hapuppy support vision/image inputs?">
  Yes. For models that support multimodal input (GPT-4o, Claude Sonnet, Gemini), you can send images in your messages. See [Chat Completions](/api-reference/chat/completions#vision) for details.
</Accordion>

<Accordion title="How do I get an API key?">
  1. Sign up at [hapuppy.com/register](https://hapuppy.com/register) — you start on the free tier with 100K daily credits
  2. (Optional) Purchase a one-time credit pack from the dashboard to unlock all 100+ models
  3. Generate an API key from the dashboard

  See the [Quickstart](/quickstart) guide for step-by-step instructions.
</Accordion>

<Accordion title="What payment methods are accepted?">
  Payments are processed via Creem. Credit/debit cards are accepted.
</Accordion>

<Accordion title="Are there subscriptions or recurring charges?">
  No. Hapuppy uses one-time credit packs — you pay once, and the credits go into your vault and never expire. There is nothing to cancel.
</Accordion>

<Accordion title="Can I get a refund?">
  Yes, within 7 days of purchase as long as you have not consumed a significant portion of the credit pack. Contact [support@hapuppy.com](mailto:support@hapuppy.com) with your order details.
</Accordion>

<Accordion title="How do I contact support?">
  Email us at [support@hapuppy.com](mailto:support@hapuppy.com).
</Accordion>
