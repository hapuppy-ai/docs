title: "Verify Account"
description: "Bind your Hapuppy account to a Discord account to unlock API access."
---

After registering, every Hapuppy account must complete a one-time verification step before the API can be used. Verification is done by linking your account to a Discord account through our official Discord server.

## Why verify?

- **Prevent abuse** by automated scrapers and shared keys
- **Tie each account to a single real person** — one Hapuppy account, one Discord identity
- **Unlock API access** — without verification, API requests are rejected

## Verification steps

<Steps>

<Step title="Sign in to the dashboard">
  Open the [dashboard](https://hapuppy.com/en/dashboard) and sign in with the email you registered.

  You'll see a banner at the top of the page prompting you to verify before the API will accept your requests.
</Step>

<Step title="Join the Hapuppy Discord server">
  Click the link in the verification banner — or join directly via [discord.gg/YWayJmZKCu](https://discord.gg/YWayJmZKCu).
</Step>

<Step title="Bind your Discord account">
  In the dashboard's verification banner, click **Bind Discord** and authorize the Hapuppy bot to read your Discord identity.

  <Warning>
    One Hapuppy account can only be bound to **one** Discord account, and one Discord account can only verify **one** Hapuppy account. The binding cannot be reused — choose carefully.
  </Warning>
</Step>

<Step title="Start using the API">
  Once binding succeeds, the verification banner disappears and your API key starts accepting requests immediately.
</Step>

</Steps>

<Info>
  Verification unlocks API access. Once you have purchased credits, every model is available, including **Claude**. No separate application is required.
</Info>

## Troubleshooting

<AccordionGroup>

<Accordion title="The verification banner doesn't disappear after binding">
  Refresh the dashboard once. If it persists, sign out and sign back in — the session may be holding a stale verification state.
</Accordion>

<Accordion title="This Discord account is already bound to another Hapuppy account">
  Each Discord account can only bind a single Hapuppy account. If you have an older Hapuppy account you no longer use, contact [support@hapuppy.com](mailto:support@hapuppy.com) to release the binding before retrying.
</Accordion>

<Accordion title="I can't join the Discord server">
  Make sure your Discord account is in good standing (not rate-limited by Discord, age requirement satisfied). If the invite link expired, grab a fresh one from the dashboard banner or footer.
</Accordion>

<Accordion title="I want to switch the bound Discord account">
  Rebinding is not self-service — email [support@hapuppy.com](mailto:support@hapuppy.com) from your registered email with the old and new Discord usernames.
</Accordion>

</AccordionGroup>
