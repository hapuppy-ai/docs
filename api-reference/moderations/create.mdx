---
title: "Create Moderation"
description: "Classify text for potentially harmful content across safety categories."
---

```
POST https://api.hapuppy.com/v1/moderations
```

Checks whether text contains potentially harmful content (hate, harassment, self-harm, sexual, violence, etc.). Use this before forwarding user-generated content to a chat model, posting to a feed, or storing in a public surface.

## Request Body

<ParamField body="input" type="string | string[]" required>
  Text to classify. Pass a single string or an array to batch classify multiple snippets.
</ParamField>

<ParamField body="model" type="string" default="omni-moderation-latest">
  The moderation model. Defaults to the latest multilingual model. Other options include `text-moderation-latest` and `text-moderation-stable`.
</ParamField>

## Response

<ResponseField name="id" type="string">Unique identifier for this moderation request.</ResponseField>
<ResponseField name="model" type="string">The model that performed the classification.</ResponseField>
<ResponseField name="results" type="array">
  One result object per input.

  <Expandable title="Result object">
    <ResponseField name="flagged" type="boolean">`true` if **any** category is violated.</ResponseField>
    <ResponseField name="categories" type="object">Per-category boolean flags (e.g., `hate`, `harassment`, `self-harm`, `sexual`, `violence`, plus sub-categories like `hate/threatening`).</ResponseField>
    <ResponseField name="category_scores" type="object">Per-category confidence scores between 0 and 1.</ResponseField>
  </Expandable>
</ResponseField>

## Examples

### Single input

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-hapuppy-xxx",
    base_url="https://api.hapuppy.com/v1"
)

resp = client.moderations.create(
    model="omni-moderation-latest",
    input="I want to learn about chemistry."
)

result = resp.results[0]
if result.flagged:
    print("Content flagged.")
else:
    print("OK to proceed.")
```

```typescript TypeScript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "sk-hapuppy-xxx",
  baseURL: "https://api.hapuppy.com/v1",
});

const resp = await client.moderations.create({

console.log(resp.results[0].flagged ? "flagged" : "ok");
```

### Batch inputs

```python Python
resp = client.moderations.create(
    model="omni-moderation-latest",
    input=[
        "Hello, how are you?",
        "Some questionable text here.",
        "Plain factual statement."
    ]
)

for i, r in enumerate(resp.results):
    print(f"[{i}] flagged={r.flagged}")
```

## Threshold-Based Filtering

The default `flagged` boolean is suitable for most cases. If you need stricter or looser policies, evaluate `category_scores` against your own thresholds.

```python Python
resp = client.moderations.create(
    model="omni-moderation-latest",
    input=user_text
)

scores = resp.results[0].category_scores
if scores.violence > 0.3 or scores.harassment > 0.3:
    raise ValueError("Content too risky to forward")
```
