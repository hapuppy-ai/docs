---
title: "List Videos"
description: "List all video generation jobs for the authenticated user."
---

```
GET https://api.hapuppy.com/v1/videos
```

Returns the history of video generation jobs associated with your API key, including queued, in-progress, completed, and failed jobs. Useful for dashboards, retry workflows, and cleaning up old jobs.

## Query Parameters

<ParamField query="limit" type="integer" default="20">
  Number of jobs to return. Range 1–100.
</ParamField>

<ParamField query="after" type="string">
  Cursor for pagination — pass the `id` of the last job from the previous page.
</ParamField>

<ParamField query="order" type="string" default="desc">
  Sort order by creation time: `asc` or `desc`.
</ParamField>

<ParamField query="status" type="string">
  Filter by status: `queued`, `in_progress`, `completed`, `failed`, `cancelled`.
</ParamField>

## Response

<ResponseField name="object" type="string">Always `list`.</ResponseField>
<ResponseField name="data" type="array">
  Array of video job objects (see [Get Video](/api-reference/videos/get#response) for the full schema).
</ResponseField>
<ResponseField name="has_more" type="boolean">`true` if more results exist beyond this page.</ResponseField>
<ResponseField name="first_id" type="string">ID of the first job in this page.</ResponseField>
<ResponseField name="last_id" type="string">ID of the last job in this page — pass as `after` to fetch the next page.</ResponseField>

## Examples

<CodeGroup>

```python Python
import requests

resp = requests.get(
    "https://api.hapuppy.com/v1/videos",
    headers={"Authorization": "Bearer sk-hapuppy-xxx"},
    params={"limit": 20, "status": "completed"},
)

for job in resp.json()["data"]:
    print(f"{job['id']}: {job['status']} ({job['model']})")
```

```typescript TypeScript
const resp = await fetch(
  "https://api.hapuppy.com/v1/videos?limit=20&status=completed",
  { headers: { Authorization: "Bearer sk-hapuppy-xxx" } }
);

const { data } = await resp.json();
for (const job of data) {

```

### Paginate through all jobs

```python Python
HEADERS = {"Authorization": "Bearer sk-hapuppy-xxx"}
all_jobs, after = [], None

while True:
    params = {"limit": 100}
    if after:
        params["after"] = after
    page = requests.get("https://api.hapuppy.com/v1/videos",
                        headers=HEADERS, params=params).json()
    all_jobs.extend(page["data"])
    if not page["has_more"]:
        break
    after = page["last_id"]

print(f"Total jobs: {len(all_jobs)}")
```
