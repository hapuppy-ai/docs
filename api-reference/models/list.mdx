title: "List Models"
description: "List all models available to your API key."
---

```
GET https://beta.hapuppy.com/v1/models
```

Returns the complete list of models available through Hapuppy. Use this endpoint to programmatically discover model IDs, owners, and creation timestamps — useful for building model pickers, filtering by provider, or detecting newly added models.

## Authentication

Requires a valid `sk-hapuppy-*` API key in the `Authorization` header. See [Authentication](/guides/authentication).

## Response

<ResponseField name="object" type="string">
  Always `list`.
</ResponseField>

<ResponseField name="data" type="array">
  Array of model objects.

  <Expandable title="Model object">
    <ResponseField name="id" type="string">
      The model identifier (e.g., `claude-sonnet-4-20250514`). Use this value in the `model` parameter of other endpoints.
    </ResponseField>
    <ResponseField name="object" type="string">
      Always `model`.
    </ResponseField>
    <ResponseField name="created" type="integer">
      Unix timestamp of when the model was first available on Hapuppy.
    </ResponseField>
    <ResponseField name="owned_by" type="string">
      The upstream provider that owns the model (see table below).
    </ResponseField>
  </Expandable>
</ResponseField>

## Examples

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-hapuppy-xxx",
    base_url="https://beta.hapuppy.com/v1"
)

models = client.models.list()

for m in models.data:
    print(f"{m.id} — {m.owned_by}")
```

```typescript TypeScript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "sk-hapuppy-xxx",
  baseURL: "https://beta.hapuppy.com/v1",
});

const models = await client.models.list();

for (const m of models.data) {
  console.log(`${m.id} — ${m.owned_by}`);
}
```

```bash cURL
curl https://beta.hapuppy.com/v1/models \
  -H "Authorization: Bearer sk-hapuppy-xxx"
```

</CodeGroup>

### Group by provider

```python Python
from collections import defaultdict
from openai import OpenAI

client = OpenAI(api_key="sk-hapuppy-xxx", base_url="https://beta.hapuppy.com/v1")

grouped = defaultdict(list)
for m in client.models.list().data:
    grouped[m.owned_by].append(m.id)

for provider, ids in sorted(grouped.items()):
    print(f"\n{provider}:")
    for mid in sorted(ids):
        print(f"  - {mid}")
```
