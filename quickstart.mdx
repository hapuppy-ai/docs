<Steps>

<Step title="Create an account">
  Sign up for a free account at [hapuppy.com/register](https://hapuppy.com/register).
</Step>

<Step title="Choose a plan">
  Start free, or purchase a one-time credit pack. Credits in the vault never expire.

  | Plan | Price | Credits | Notes |
  |------|-------|---------|-------|
  | Free | $0 | 100K daily | Basic models, resets each day |
  | Lite | $9.99 one-time | 30M | All 100+ models, never expires |
  | Standard | $19.99 one-time | 120M | All models, never expires (popular) |
  | Pro | $36.99 one-time | 240M | All models + priority routing, never expires |

  Paid tiers share a 100 RPM rate limit; the Free tier is 10 RPM. Purchase through the [Credits Packs](https://hapuppy.com/en/dashboard/billing) page; payments are processed via Creem.
</Step>

<Step title="Generate an API key">
  Navigate to **Dashboard → API Keys** and click **Create Key**. Your key will look like:

  ```
  sk-hapuppy-xxxxxxxxxxxxxxxxxxxxx
  ```

  <Warning>
    Store your API key securely. Do not share it or commit it to version control.
  </Warning>
</Step>

<Step title="Send your first request">
  Use any OpenAI-compatible SDK or make a direct HTTP request.

  <CodeGroup>

  ```python Python
  from openai import OpenAI

  client = OpenAI(
      api_key="sk-hapuppy-xxx",
      base_url="https://beta.hapuppy.com/v1"
  )

  response = client.chat.completions.create(
      model="claude-sonnet-4-20250514",
      messages=[
          {"role": "user", "content": "What is the meaning of life?"}
      ]
  )

  print(response.choices[0].message.content)
  ```

  ```typescript TypeScript
  import OpenAI from "openai";

  const client = new OpenAI({
    apiKey: "sk-hapuppy-xxx",
    baseURL: "https://beta.hapuppy.com/v1",
  });

  const response = await client.chat.completions.create({
    model: "claude-sonnet-4-20250514",
    messages: [
      { role: "user", content: "What is the meaning of life?" }
    ],
  });

  console.log(response.choices[0].message.content);
  ```

  ```bash cURL
  curl https://beta.hapuppy.com/v1/chat/completions \
    -H "Authorization: Bearer sk-hapuppy-xxx" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "claude-sonnet-4-20250514",
      "messages": [
        {"role": "user", "content": "What is the meaning of life?"}
      ]
    }'
  ```

  </CodeGroup>
</Step>

<Step title="Try different models">
  Swap the `model` parameter to try any of our 100+ supported models:

  ```python Python
  # Try GPT-4o
  response = client.chat.completions.create(
      model="gpt-4o",
      messages=[{"role": "user", "content": "Hello!"}]
  )

  # Try Gemini
  response = client.chat.completions.create(
      model="gemini-2.5-pro-preview-05-06",
      messages=[{"role": "user", "content": "Hello!"}]
  )

  # Try DeepSeek
  response = client.chat.completions.create(
      model="deepseek-chat",
      messages=[{"role": "user", "content": "Hello!"}]
  )
  ```

  See the full list of available models on the [Models](https://hapuppy.com/en/dashboard/models) page.
</Step>

</Steps>
